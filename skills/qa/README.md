# QA Skills

QA planning and autonomous Android, API, browser, performance, and failure-triage workflows.

## Model-invoked

Model- or user-reachable via skill name and trigger phrasing.

- **[z-bdd](./z-bdd/SKILL.md)** — Define BDD acceptance scenarios for a UI, API, or CLI.
- **[z-qa-analyst](./z-qa-analyst/SKILL.md)** — Map requirements to assertions, execution evidence, and gaps.
- **[z-qa-android](./z-qa-android/SKILL.md)** — Test Android apps with adb, a headless emulator, or a physical device.
- **[z-qa-api](./z-qa-api/SKILL.md)** — Test API journeys through a running service.
- **[z-qa-browser](./z-qa-browser/SKILL.md)** — Test browser journeys, accessible locators, Playwright assertions, or screenshot regressions.
- **[z-qa-debugger](./z-qa-debugger/SKILL.md)** — Triage failed or flaky tests.
- **[z-qa-orchestrator](./z-qa-orchestrator/SKILL.md)** — Run acceptance and required regression checks with the project runner.
- **[z-qa-performance](./z-qa-performance/SKILL.md)** — Define workload, pass thresholds, and stop conditions for a bounded load test.
- **[z-qa-spec-writer](./z-qa-spec-writer/SKILL.md)** — Create test scaffolding and verify test discovery in the project’s framework.
