# Delivery checks

Use [[z-accessibility]] for accessibility requirements and [the main skill](../SKILL.md) for implementation defaults. This checklist records the delivered result without duplicating those rules.

- Complete the agreed user flow and relevant loading, empty, error, and success states.
- Check supported viewports, themes, long content, text resizing, and reflow.
- Exercise keyboard navigation, dialog focus, labels, announcements, and reduced motion.
- Confirm the implemented tokens and components match the project's design system.
- Run the project's bounded checks and report the actual results.
- Measure claimed performance improvements on representative content and devices.
- Record remaining limitations, including unsupported environments and manual checks not performed.

An automated accessibility score is diagnostic evidence, not proof of WCAG conformance.
