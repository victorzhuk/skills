# Product Skills

Skills for turning a raw idea into a shippable OpenSpec change — grilling, design briefs, cloud-design handoff, and PRD authoring. They chain: grill → brief → handoff → PRD → OpenSpec changes; each hands off to the next via its closing links.

## Model-invoked

Model- or user-reachable via skill name and trigger phrasing.

- **[z-market-research](./z-market-research/SKILL.md)** — Research competitors, pricing, positioning, and demand.
- **[z-grill-me](./z-grill-me/SKILL.md)** — Clarify a request or sharpen a prompt before implementation.
- **[z-grill-with-docs](./z-grill-with-docs/SKILL.md)** — Clarify requirements and record agreed terms and decisions in their existing project documents.
- **[z-design-brief](./z-design-brief/SKILL.md)** — Define screens, states, visual constraints, and acceptance criteria for a UI.
- **[z-design-handoff](./z-design-handoff/SKILL.md)** — Prepare a design handoff from a screen brief for Figma Make, Stitch, v0, or Lovable.
- **[z-to-prd](./z-to-prd/SKILL.md)** — Write a product requirements document from agreed decisions, a design brief, and available prototype results.
- **[z-prd-to-openspec](./z-prd-to-openspec/SKILL.md)** — Split a PRD into independently verifiable OpenSpec changes.
